# Harvestworks

A cozy isometric production-chain farming game that runs in the browser.

Play: https://zcgrimshaw.github.io/harvestwork/

- `index.html` — page and interface
- `data.js` — items, recipes, stations, discoveries, contracts
- `art.js` — placeholder pixel art
- `game.js` — gameplay, rendering and saving
- `version.json` — build id; open games show a "new version ready" banner when it changes

Saves are kept in each player's own browser (localStorage). Nothing is sent anywhere.
